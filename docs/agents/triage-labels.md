# Triage Labels

Padel Up uses the standard 5 canonical triage labels:
- `ready-for-agent`: Unambiguous, fully specified, vertical tracer-bullet task ready for background execution.
- `needs-triage`: Newly opened issue awaiting categorization and specification.
- `needs-info`: Blocked on missing requirements, user decisions, or assets.
- `ready-for-human`: Requires physical hardware testing, secret provisioning, or human subjective approval.
- `wontfix`: Out of scope or rejected.
